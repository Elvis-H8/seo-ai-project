## 要点
哥飞 2025-09-04 专栏第 1 篇，和同日开栏帖是两份文档，本篇才开始给定义和结构。他先指出近期新词比赛前列常见游戏或游戏相关站，但比赛数字是短窗成绩，不能直接当成长期收入。定义上，这里的小游戏站不是要注册充值的网页网游，而是类似过去动画小游戏、现在多用网页技术实现的「小」游戏：规则简单、免登录即玩、多为单机或同机多人、单局时间短、以休闲为主。盈利主要靠页面广告，也有人做去广告充值。作者习惯用广告联盟的自动广告；审核期间有人会先用其他广告网络，他提醒这类网络广告很杂，可能出现色情或赌博等，若使用要在后台关掉不当类别，并仍更建议用较规范的联盟。文中带有他的注册跟踪链接，不是必须走的通道。

## 方法 / 阈值
最简单可以「一个游戏一个站」：域名常用游戏名，首页打开就能玩，整站围绕这个名字做搜索。即使以后横向增加内页和导航里的其他游戏，也强调不要改已经按该游戏名优化过的首页。无论单游戏还是多游戏，原则仍是一个关键词对应一个页面；会做单站，也就能在首页不变的前提下加更多游戏页。积累经验并能靠游戏词拿到排名后，再考虑「游戏盒子」：首页是列表而不是单个游戏，域名多用自己的品牌或品类词。也有老手第一天就以上线目标游戏为首页，同时在侧栏和导航放更多游戏，既不是纯单页，也不是列表型盒子。有人担心同一套代码上多个站、内页雷同会被判重复，作者的回答是每个站都要生成不一样的内容，不要偷懒。这是在强调内容要有差异，并不能理解成可以用同一套薄页面批量铺站。生态上画出开发者、发行平台和站长：平台连接开发和流量，玩家在嵌入的游戏里看到的广告通常归平台和开发者，站长赚的是游戏区域以外页面上的广告；有的平台会主动提供嵌入代码，因为他们也要曝光和站内导流。作者同时写得很直白：社群里说的这类站常常游离在正规授权链之外，许多游戏来源「严格来说没有得到授权」，只是当时管理并不严；随即又说，并不是要故意去拿未授权的游戏，而是使用对方公开提供的嵌入。这两句话必须分开：有授权或平台提供的嵌入，才是可讨论的合作方式；「管得不严」不能当成可以复制未授权游戏的许可。文末预告下一篇会写如何嵌入、单页搜索优化和体验，那一篇不在本篇范围内。

## 案例
单游戏站举了经典数字益智站；盒子站举了品类域名的列表站；老手形态举了两个以特定游戏名为首页的站。后两个例子涉及已有商业或热门游戏名称，只说明形态，不构成可以商用这些作品的授权。比赛榜里的访问和奖金是当时名次，域名已打码。

## 风险 / 冲突 / 实操注意
把「来源不正经但管得不严」写成行业现状，容易被读成鼓励未授权搬运，实践中不应采用。商业游戏名做域名和首页，有商标与版权风险。审核期使用较野的广告网络可能伤害用户和账户。多站、站群要各自有实质内容，不能靠同一套页面群发。本阶段不建站、不嵌游戏、不申请广告。

## 证据位置

## 要点

用多个 IP 绕过查询次数限制，属于规避频率限制，不执行、不编写。不要把文中的查询步骤写成可运行脚本，也不要去调用或恢复作者未公开的接口。域名注册人信息属隐私，不回显截图中可能出现的联系人字段。拿老域名参加「新词比赛」是否合适，正文没有给出结论。

## 要点
2025-01-16 专讲「精品工具页面」，并与上周提到的思路衔接。作者给出三个公式：工具页+落地页+结果展示页=精品工具页面；精品工具页面+低竞争关键词=排名和曝光；排名和曝光+优秀用户行为数据=搜索结果前几名。做法是找准一个大需求，再在其下做大量低竞争长尾词的精品页；「精品」指不粗制滥造，力求每个上线页都能拿到排名和曝光，再靠真实用户行为把排名推上去，循环；许多这样的内页还可能带动首页主词。三个组成部分：工具页可以是提交后跳转，也可以在当前页完成（Canva 常在落地页放表单，游戏站多在当前页完成）；落地页承接流量，SEO 落地页需要后端渲染足够文字，让爬虫理解主题；结果展示页可以是用户生成或站方精选的结果列表，如 AI 图片/音乐/视频列表。把三者合并到同一页面，既是落地、又是工具、又是结果展示，即精品工具页。学员理解成「结果不要跳到第二页，以增加停留」，作者部分认可，并对比海外常见 AI 工具站模式：www 或裸域用 Framer 等做官网博客和落地页，app 子域才是需登录的工具。他认为在谷歌眼里像两个站，行为数据在没有获客页的 app 子域，官网却是内容页、行为数据差；想超越就把页面合并到同一域名，甚至同一页面。与传统落地页最大差别是页面可交互，而不只是一个跳到真正工具的 CTA。三个公式的前提仍是一个关键词一个页面；同一功能的三种说法可以做成三个页面。文中有「不理解就信哥飞去执行就会有流量」「把课堂内容扔给 AI 再提问」的说法。本篇与 OpVv 里提到的精品页思路相呼应。

## 方法 / 阈值
有启发的结构是：获客页本身就要能完成工具任务并展示结果，尽量不要把可互动部分关在需登录的子域里。三个「公式」是框架，不是因果关系定律。为爬虫堆大量文字时，仍应是对用户有用的说明，而不是空壳。

## 案例
Canva 表单位置、游戏站当前页完成、www/app 子域拆分，都是模式举例，没有给出合并前后的对比数据。

## 风险 / 冲突 / 实操注意
「信了去执行就会有流量」不能当承诺。把官网和工具合并是一种站型选择，不是所有产品都适合把登录后功能完全放到公开页。不按本篇去建站或改现有站点。

## 证据位置
与「一页一词、低竞争长尾、用户行为会反哺排名、质量优于批量生成」相符。可与 OpVv 的精品页笔记对照。

## 要点

## 要点
2025-01-16。课堂开头是学员讨论 Cloudflare Crawler Hints：有人按 Bing 教程打开后，每天推送的多是 icon、robots，而不是实际上线网页；另一位说自己也一样，建议「还是自己写个脚本推」。作者没有展开回答这个问题，转去复习排名。核心表述：不同词难度不同；高难度词已有在位者，新站不能指望立刻平起平坐，你的上升意味着别人下降，所以要内容、体验、权重都更好，经观察后才慢慢给流量。新词可以今天上线、明天有流量，因为竞争少，不太需要权重。自己发明的、没人用过的品牌名，收录后搜这个名字多半能排第一，但若没有推广，通常只有自己会搜，没有流量。因此要找「有人搜索、有共识」的词。若某词在社交爆火（举例上半年「粘土滤镜」），抢先做页可能轻松靠前；随后更高权域名可能超过你。要稳住：提升停留时间、人均打开页数，降低跳出，增加外链。什么都不做，先发优势会消失。高难度词不要幻想上线后不动、几个月就排上去。作者把过程写成：先积极表现、争取曝光，谷歌用小流量测试你能否接住，能接住再给更多，循环；一旦接不住或出现更强站，排名会掉。文中强调「网站没外链是不行的」；搞外链的方法仍是「抄作业」：看到任何站都去看它的外链，分析如何获取，找出自己也能获取的再去发布。良辰美补充：外链助推加内页优化，都要在体验更好的前提下增加数量以拉长停留。

## 方法 / 阈值
可保留的机制是：老词看竞争和是否真比在位者好；新词/共识词才可能快；品牌自造词没搜索就没流量；平均或阶段性流量是小流量测试，不是一次给满。Crawler Hints 失效和「自写推送脚本」本篇没有可核验步骤，不展开、不编写。抄外链作业只作观察。

## 案例
粘土滤镜是举例，没有给出该词的结果数据。Crawler Hints 只是学员现象描述。

## 风险 / 冲突 / 实操注意
「没外链不行」与同日 CBln 案例「几乎没主动外链也能靠先发排前」冲突，应并读，都不是阈值。「抄外链作业去发布」有群发和链接方案风险，只评述。不要编写索引推送或抓取脚本。

## 证据位置
与「新词快、老词慢、用小流量测试、先发会被追上」的既有对照一致。外链重要性在不同课堂里表述力度不一。

## 要点
2025-01-16，用作者自己一个站点近七天的控制台数据讲曝光、点击、平均排名和点击率。曝光是页面出现在搜索里的次数，点击是被点的次数，平均排名是这些曝光里名次的平均，点击率是点击除以曝光。他先强调：没有曝光就不会在报告里出现排名，但从因果上看，往往是先有排名才会被看到。随后纠正自己前面一句话：报告里的曝光，一定是用户在结果里看到了该页才会记，因此若某次曝光对应的排名很靠后，就真的有人翻到了那一页，而不能全解释成被平均出来的假象。官方口径大致是结果出现在该页结果中即可能计一次，有时更严，要进入视野；用户没翻到的页不会记。他用不同页码做平均的演算比较粗糙，只适合理解「平均是多次曝光的均值」。后半讲如何按查询词、设备、日期层层过滤，以及用比较看不同时间段哪里变差，用来解释流量突然上升或下降。文中有个别用词笔误，不影响理解。

## 方法 / 阈值
看控制台时要分清平均值和单次曝光，用筛选下钻到词、页、地区和设备，再用时间比较找变化，而不是只看总点击。

## 风险 / 冲突 / 实操注意

## 要点

## 要点
2025-01-15，把「举全站之力」讲成：别人用内页就能排上的词，自己若用整站只盯这个词，长期也有机会追上，甚至超过那些内页；这靠的是扎实内页和合理内链，而不是只做首页。只靠首页就排上，往往说明竞争还不高，基础不牢，别人花时间可能超过你。作者摘了某篇解读里几项非官方的比例（持续出内容、领域专长、新鲜度、可信、内链），加总约一半，用来说明内页和内链重要，这些比例不是官方权重。反面是不要盲目上与主词无关的几十万页，有些内容一开始就不要让爬虫抓。他把「精品页」说成控制台里要有曝光和点击，并自创一个比值：有曝光点击的页数，除以爬虫发现的页数。先用几个站试算，又因数值太小改成万分比，再因导出错表和控制台最多导出一千条，把适用范围收窄到「有点击曝光的页还不到一千、最好在总页数一万以内就先试策略」。及格线是他拍脑袋定的万分之百，低于此应先停更、处理旧页、改策略，样本还不够，不能当普遍标准。内容型工具站的旧做法（用户每生成一条就单独成页）被他否定，因为容易重复抢词、页面不聚焦；改成先从对手有流量的页循环挖词，给用户内容打上词标签，某个词积累到若干条相关内容后再做词页，在页里解释该词并展示相关生成物。词页才是给搜索看的页，单条生成物可不准收录。组织上仍是一页一词、分门别类、树状层级、面包屑、根栏目进顶栏、列出同级和下级，重要内页多给入口。改目录结构时，旧地址不要改，只让新内容用新路径。

## 方法 / 阈值
先按会搜的词做内页，再用内链把层级连起来，而不是有什么内容就发什么页。用户生成内容先归到词下面，够数再做词页。新站先在较小规模上用控制台看有多少页真正获得曝光点击，再决定是否继续扩。

## 案例
某讲者的站点从年末上线到次年春季访问起来、搜索占比过半且未投广告，是单一案例。几个被代入自创比值的站点数字，受导出上限和一度用错表格影响，后来作了修正。一个贴纸工具站的旧方案被当作需要改正的例子。

## 风险 / 冲突 / 实操注意
文中的排名因素百分比不是官方权重。自创比值和「万分之百及格」是经验拍板，算过几次就改了口径，不能当考核公式。品牌词域名只是计算样本。不要把「先做一万页再放量」理解成可以随后无限制堆页。查流量用自己的正规账号。

## 要点
2025-02-27 科普课，解释为什么 Ahrefs 里能看到的外链在 GSC 里不一定看得到：爬虫还没爬到，以及各家数据和展示时机不同。互联网被说成实体线路和页面超链接两张网；网站部署在少关机的服务器上，页面靠链接互通。浏览器打开网页是客户端向服务器发 GET 取 HTML；提交内容（如发推）一般是 POST；服务器调别人的 API 时，发起方是客户端。请求格式由 HTTP 规定。作者把 HTTP 说成明文纯文本协议，二进制也常被编码成文本再传；HTTPS 是在收发两端加解密，加密后传输的仍是文本——这是便于理解的简化，实际请求体也可以直接是二进制，不必都走 Base64。网站返回的是可阅读的 HTML，浏览器再渲染。后端渲染是第一次请求就带完整内容；前端渲染通常先返回壳和 JS，再由 JS 继续请求并在前端插入内容。互联网没有统一数据库，想知道有多少页就要派爬虫：发请求下载 HTML，抽链接，判断是否抓过、要不要再抓或新抓，放入待爬队列，不断取任务。爬取消耗资源，所以会有「值不值得爬」的策略。谷歌给每个站的爬虫预算不同，新站通常少、高权站多；若大量生成低质量页，爬过又拿不到排名，就可能调低预算、不再爬新页、不索引甚至去掉已有索引，GSC 里未索引会增加；若还继续造同样的垃圾页，作者称为会「惩罚」不再给曝光，用来提醒停止。各家爬虫独立运行，所以谷歌爬到的 Ahrefs 未必爬到，反过来也一样；GSC 的反向链接展示还有延迟，Ahrefs 等往往更快放出，于是同一批外链在不同平台会有的已显示、有的还没有。这也解释了为什么很多 AI 搜索不自建全网爬虫：成本极高，于是 ChatGPT 用 Bing 等接口，其他产品也可能用 Google 或其他搜索接口。作者同时提到 OpenAI 有自己的爬虫，但目的不是爬完全网，而是抓一批高质量页做训练数据，以及在被要求总结某些网页时实时抓取。

## 方法 / 阈值
有帮助的概念是：搜索引擎先要能抓到后端可见的 HTML；外链在 Ahrefs 和 GSC 不一致常常只是爬取和展示不同步，不必立刻判断链接无效；大规模低质量页会消耗并可能降低抓取预算。HTTPS 和请求体格式的细节以标准文档为准。所谓「惩罚」更接近质量与抓取系统的反应，不一定等于 GSC 里的人工处罚。

## 风险 / 冲突 / 实操注意
不要据此去写全网爬虫或绕过抓取限制。不要把「Ahrefs 有、GSC 还没有」理解成一定被谷歌无视或一定会被收录。低质量批量页的警告与精品页主张一致，应遵守，而不是想办法规避预算。
