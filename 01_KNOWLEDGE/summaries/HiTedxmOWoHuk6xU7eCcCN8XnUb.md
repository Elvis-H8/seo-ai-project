## 概念
说明除谷歌外，Bing 及 Yahoo/DuckDuckGo 等也可贡献可观流量；作者认为其它搜索引擎爬虫较弱，更依赖 Sitemap 和站长提交，而谷歌更爱自己发现。

## 方法
作者发现自己某站未被 Bing 收录后的动作（正文列表第 1、4 条在转写中为空，可能原是截图步骤）：补 Sitemap；按 Bing 站长后台扫描出的问题逐条改（缺 Description、缺 H1、Title 过长等）；在 Cloudflare 开启「主动推送」。群友「帆」补充：甚至未刻意提交，只打开 Cloudflare 域名→缓存→配置→Crawler Hints，随后出现 Bing/Yahoo/Yandex/DuckDuckGo/Brave 来源。群内讨论建议上站时记得提交 Bing（有人 GA 有用户而 GSC 几乎无点击，实际大头来自 Bing）。

## 阈值 / 主张
无统一数值门槛。作者称自己处理后「稳定每天两三百个点击」（文中图为 2025-01-01 至 03-05）。收录时效未量化。

## 案例
作者自己的站：处理后 Bing 日点击约两三百。群友站：Top Sources 中 Bing 11.5k，Direct 3.7k，Google 3.1k。Joyqi 推文称思否来自 Bing 的流量已是百度两倍以上（2025-02-21）。均为个案，时点在 2024–2025 冬春。

## 依赖
Bing Webmaster、Sitemap、Cloudflare Crawler Hints；统计对比用 GA/GSC。

## 风险 / 不宜无依据背书
转写缺第 1、4 步，可能遗漏「提交 Bing 站长平台 / IndexNow」等关键动作，实践时需对照原图或 Bing 官方流程，不能只靠残缺列表。Crawler Hints 是否等于收录承诺，官方含义是向爬虫提供变更提示，效果因站而异。「谷歌不需要 Sitemap」是作者猜测。数据图无法在本轮复核。
