## 要点
2025-02-10。以 geometry dash 为例：这是群里很多人找过的老词，KD 很高，但当时排前的竟是两个2024年新站（一个2月域名，一个6月域名）。作者据此说高 KD 老词也不是不能做。截图里第一名是6月注册的域名，约有1400多个外链域名，配合「做好网站和体验」，被用来证明可以挑战高难度词。流量曲线称近三个月从十几万到五十多万再到约九十五万。外链做法仍是抄作业，理由是「当前靠前的站用这些外链拿到了排名，就证明有效，最差也是无害的，所以直接无脑抄作业就好了」——这是很强且不可靠的推论。布局上，这是典型游戏站：不要一模一样复制，而是拆功能模块再让 AI 做类似的；首页围绕核心词，第一屏正中给出游戏入口；侧边栏和游戏两侧、下方放更多游戏。若用游戏名做域名，仍可做更多相关游戏和内页，只要首页对着那个核心词。该站当时被收录五百多页，作者认为「看起来完善」也是拿到第一的因素之一，不能只有一两页像练习作业。文中后段突然插入「这篇文章举例的两个网站 API 成本都才1毛钱，完全可靠广告赚回；另一个烧钱站 API 是0.5美元，说是1毛钱的35倍，应避开这么贵的需求和 API」——与 geometry dash 案例衔接生硬，更像另一篇文章的片段；且1毛与0.5美元单位不同，35倍需按人民币换算才能对上，不能直接当成本公式。原则部分：多数 SEO 要慢慢积累；只有新词才可能一周内有流量，但新词可遇不可求，不能守株待兔，老词也要做，并做好三五个月才见效的心理准备。文末有决心、耐心、细心、平常心的鼓励，以及「不必做成上市公司，每月几万美金已经很好」。最后一句又补「把游戏放自己 CDN 里最可控」，与正文主体关系不完整。

## 方法 / 阈值
可记下的是：KD 高不等于新站完全没机会，但要看对手是否真强、自身体验和内容是否完整；老词要按月而不是按周预期。抄外链、「无脑有效或至少无害」和把正版游戏放到自己 CDN，都不列入方法。API 成本段落当作另段笔记，不并进这个案例。

## 案例
两个2024年新站排在 geometry dash 前面、约1400个外链域名、三个月内访问升到约95万，都是当时 Ahrefs 一类第三方数据。不能外推「高 KD 加一千多外链就能重现」。API 收支是作者其他站点的自称，且单位混用。

## 风险 / 冲突 / 实操注意
Geometry Dash 是有版权的游戏，把游戏放到自己的网站或 CDN、或「让 AI 做一样的」有侵权风险，只评述不模仿。「无脑抄外链一定有效或无害」不成立，垃圾或付费链同样可能有害。不执行建站、外链或托管游戏。

## 证据位置
与「新词快、老词慢、先发会被更完整的后来者追上、KD 会失真」相符。外链「无脑抄」与同日 W1SU 末尾「不要买垃圾外链」也互相冲突，应并读。
