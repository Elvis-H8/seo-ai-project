## 要点
2026-09-07，同一作者 Simon 的短帖：像 wan3 这类模型接口很复杂，可接受参考视频、图片甚至 PDF，文档又写不全，坑很多。举例称输入视频加输出视频总时长不能超过30秒，用户因此经常生成失败，前端没有报错，接口也只返回生成失败，体验很差，后来问模型才找到原因，排查非常耗时。他的经验是不能只参考官方 API 文档，还要去 GitHub 找较成熟的调用库（文中写作 comyfui，应指 ComfyUI 一类），里面往往已有更完整的校验和提示，可以节省时间。没有给出接入代码或失败率数据。

## 方法 / 阈值
原则是：复杂生成接口要把限制做进前端预校验，并对照成熟开源实现，而不是等失败后再猜。具体时长限制以各模型当前文档为准，文中30秒只是作者当时的发现。
