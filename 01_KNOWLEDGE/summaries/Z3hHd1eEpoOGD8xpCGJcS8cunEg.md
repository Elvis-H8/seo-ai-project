## 要点
2025-02-27 科普课，解释为什么 Ahrefs 里能看到的外链在 GSC 里不一定看得到：爬虫还没爬到，以及各家数据和展示时机不同。互联网被说成实体线路和页面超链接两张网；网站部署在少关机的服务器上，页面靠链接互通。浏览器打开网页是客户端向服务器发 GET 取 HTML；提交内容（如发推）一般是 POST；服务器调别人的 API 时，发起方是客户端。请求格式由 HTTP 规定。作者把 HTTP 说成明文纯文本协议，二进制也常被编码成文本再传；HTTPS 是在收发两端加解密，加密后传输的仍是文本——这是便于理解的简化，实际请求体也可以直接是二进制，不必都走 Base64。网站返回的是可阅读的 HTML，浏览器再渲染。后端渲染是第一次请求就带完整内容；前端渲染通常先返回壳和 JS，再由 JS 继续请求并在前端插入内容。互联网没有统一数据库，想知道有多少页就要派爬虫：发请求下载 HTML，抽链接，判断是否抓过、要不要再抓或新抓，放入待爬队列，不断取任务。爬取消耗资源，所以会有「值不值得爬」的策略。谷歌给每个站的爬虫预算不同，新站通常少、高权站多；若大量生成低质量页，爬过又拿不到排名，就可能调低预算、不再爬新页、不索引甚至去掉已有索引，GSC 里未索引会增加；若还继续造同样的垃圾页，作者称为会「惩罚」不再给曝光，用来提醒停止。各家爬虫独立运行，所以谷歌爬到的 Ahrefs 未必爬到，反过来也一样；GSC 的反向链接展示还有延迟，Ahrefs 等往往更快放出，于是同一批外链在不同平台会有的已显示、有的还没有。这也解释了为什么很多 AI 搜索不自建全网爬虫：成本极高，于是 ChatGPT 用 Bing 等接口，其他产品也可能用 Google 或其他搜索接口。作者同时提到 OpenAI 有自己的爬虫，但目的不是爬完全网，而是抓一批高质量页做训练数据，以及在被要求总结某些网页时实时抓取。

## 方法 / 阈值
有帮助的概念是：搜索引擎先要能抓到后端可见的 HTML；外链在 Ahrefs 和 GSC 不一致常常只是爬取和展示不同步，不必立刻判断链接无效；大规模低质量页会消耗并可能降低抓取预算。HTTPS 和请求体格式的细节以标准文档为准。所谓「惩罚」更接近质量与抓取系统的反应，不一定等于 GSC 里的人工处罚。

## 案例
用「在 A/B/C 三个站给 D 加外链、两天后各平台显示不同」做思想实验，没有给出可核对的实测表。OpenAI 爬虫用途是作者的概括。

## 风险 / 冲突 / 实操注意
不要据此去写全网爬虫或绕过抓取限制。不要把「Ahrefs 有、GSC 还没有」理解成一定被谷歌无视或一定会被收录。低质量批量页的警告与精品页主张一致，应遵守，而不是想办法规避预算。
