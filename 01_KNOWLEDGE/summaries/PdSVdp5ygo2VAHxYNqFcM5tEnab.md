## 要点
2026-08-31，作者 Sinan 介绍自己开源的数据系统 Dashloom。痛点是独立开发者或小团队同时运营多个产品时，数据散落在分析、支付、代码仓库和云设施里，汇总一次很慢，交给 AI 还要反复导出。系统把多数据源标准化到统一「证据层」，先用确定指标和信号找出值得关注的变化，再用接入方自己的 OpenAI 兼容模型做分析，生成带证据引用的洞察、建议和定期报告；也可用作多产品隔离的数据大盘，并能通过安装 skill 扩展。预设场景包括独立开发者、SaaS 收入、SEO 增长、Cloudflare 运维和客户报告。作者强调结论要引用证据，不把相关性直接说成因果。开源版完全自部署，接入自己的数据和接口。当时支持的数据源包括 GA、GSC、Bing 站长工具（原文写作 Bing Master）、Stripe、Lemon Squeezy、Creem、Polar、Paddle 或自有库中的收入数据，以及 GitHub、Vercel、部分 Cloudflare 产品、Supabase、D1，还有自定义 REST、手工指标和 SDK。支持 OAuth 的平台可配置接入，有的需要自行配置变量和密钥。项目地址指向 GitHub 上的 dashloom-dev/dashloom，另有中文说明；在线 cloud 版称尚未完善、可免费试用，并写「在关联数据报错的位置点击信任强制关联即可」。
